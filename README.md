# ProofLearn AI 🛡️

**Understand the code. Verify the issue. Fix it safely.**

ProofLearn AI is an AI-assisted code review prototype for beginners who use AI-generated Python code but may not have enough expertise to judge whether the result is safe, correct, or maintainable.

## What makes it different

ProofLearn AI separates **detection** from **explanation**:

1. **Detect** — Python AST + deterministic rules find concrete issues.
2. **Explain** — Gemini turns the finding into beginner-friendly language.
3. **Verify** — the user answers a short understanding check.
4. **Fix** — the system provides guided next steps.

The LLM is not treated as the source of truth for the detected issue. The deterministic finding is passed into the explanation layer.

## Architecture

```text
User / AI-generated Python code
            |
            v
   AST + deterministic rules
            |
            v
   Finding + evidence + line
            |
            v
      Google Gemini API
     (explanation layer)
            |
            v
     Understanding check
            |
            v
       Guided fix
```

## Current MVP

- Python only
- Streamlit UI
- AST-based deterministic checks
- Hardcoded credentials
- `eval()` / `exec()`
- `subprocess(..., shell=True)`
- Bare `except:`
- Mutable default arguments
- Gemini-powered explanations
- Short understanding checks
- Deterministic fallback if Gemini is unavailable
- Small team-created benchmark and unit tests

This prototype is **not** a complete security scanner and does not certify code as secure.

## Setup

### 1. Create a virtual environment

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

macOS/Linux:

```bash
source .venv/bin/activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure Gemini

Copy `.env.example` to `.env` and set your API key:

```text
GEMINI_API_KEY=your_api_key_here
GEMINI_MODEL=gemini-3.7-flash
```

Do **not** commit `.env` or your real API key.

### 4. Run

```bash
streamlit run app.py
```

or:

```bash
python run.py
```

## Dataset / evaluation

The benchmark in `data/review_benchmark.json` is self-generated by the team for prototype evaluation. It records the intended rule and severity for each sample. Expand it with more positive and negative cases before making performance claims.

Suggested measurements:

- Detection precision / recall on the benchmark
- Evidence-link accuracy (does the reported line match the finding?)
- Understanding-check pass rate
- Percentage of users who can state the root cause after the explanation

## Grounding and safety

Guidance should be grounded in a deterministic finding, project context, official documentation, an applicable standard, or another verified check. The current MVP uses deterministic code findings as its grounding source.

Do not use ProofLearn AI as a replacement for professional security review, safety certification, or legal/compliance decisions.

## Hackathon positioning

ProofLearn AI is designed around the PS3 theme: closing the expertise gap for students, self-taught developers, junior developers, and other non-expert builders who now create software with natural-language tools.

The central idea is not “generate more code.” It is to make the **judgement around generated code understandable, verifiable, and actionable**.
